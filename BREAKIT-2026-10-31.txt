D. Not fixable in a hook (now stated in README "Known gaps" and THREAT-MODEL "What's left over")
- Scripts / programs doing the harm (python3 x.py, npm run, make, a script written a step earlier).
- Names built over several steps (F=settings.json; .../$F) and renamed copies of blocked programs (cp "$(which curl)" c).
- Archives and patches unpacking into .claude/ (tar x, unzip, git apply).
- The user's own shell aliases/functions loaded into Claude Code's shell (e.g. alias gp='git push').
- Indirect secret reads inside the project (grep -r over the folder, archiving it, Grep tool over '.').
- Data carried in short approved WebFetch/WebSearch requests.
- Hook timeout = Claude Code proceeds (mitigated: worst case measured <1 s).
- Symlink swap between the guard's check and the tool's write (TOCTOU); needs a second process racing, which the
  background rules make hard but not impossible.
- Unicode look-alike names (e.g. full-width letters) are different files/programs to the OS: not a bypass, nothing to fix.
